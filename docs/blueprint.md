# **App Name**: QuizWhiz Kids

## Core Features:

- Quiz Topic Input: Text field for students and teachers to input quiz topics (e.g., 五年级语文古诗词选择题).
- AI Quiz Generation: Generative AI (Deepseek) creates 5-20 multiple-choice questions based on the inputted topic.
- Clear Quiz Display: Presents the generated quiz questions in a readable format suitable for elementary students.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to evoke a sense of trustworthiness and intelligence. It also contrasts well with white, to provide a readable UI.
- Background color: Light blue (#E1F5FE), which is a desaturated version of the primary color. It provides a non-distracting background.
- Accent color: A cheerful, contrasting yellow (#FFDA63) for buttons and highlights, creating an interactive feel for the user.
- Font: 'PT Sans', a humanist sans-serif, provides both modern clarity and approachability. The font is appropriate for both headlines and body text.
- Use bright, friendly, age-appropriate icons (e.g., lightbulbs, graduation caps) to represent different quiz categories.
- Simple, uncluttered layout with plenty of white space to make the content easy to read and navigate for young users.
- Subtle, cheerful animations on button presses or quiz completion to engage and reward students.
